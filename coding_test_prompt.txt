## Coding Problem: Event Booking System

Design and implement an event booking system in Python. The system must support the following features:

### Core Requirements

1. **Event Class**
   - Attributes: `event_id` (unique string), `title`, `description`, `capacity` (int), `booked_seats` (int, starts at 0)
   - Method: `available_seats()` returns `capacity - booked_seats`
   - Method: `is_full()` returns `True` if `booked_seats >= capacity`

2. **Booking Class**
   - Attributes: `booking_id` (unique string), `event` (reference to Event), `customer_name`, `seats_requested` (int)
   - Method: `can_book()` returns `True` if `seats_requested <= available_seats()` of the associated event
   - Method: `book()` if `can_book()` is True, increments `event.booked_seats` by `seats_requested` and returns `True`; otherwise returns `False`

3. **BookingSystem Class**
   - Attributes: `events` (dict mapping event_id -> Event), `bookings` (dict mapping booking_id -> Booking)
   - Method: `create_event(event_id, title, description, capacity)` creates a new Event and stores it
   - Method: `get_event(event_id)` returns the Event or `None` if not found
   - Method: `make_booking(booking_id, event_id, customer_name, seats_requested)` creates a Booking and attempts to book; returns `True` if booking successful, `False` otherwise
   - Method: `list_events()` returns a list of all events with their available seat counts

### Additional Requirements

4. **Input Validation**
   - `event_id` and `booking_id` must be non-empty strings
   - `capacity` and `seats_requested` must be positive integers
   - `seats_requested` must not exceed `capacity`
   - Invalid inputs should raise `ValueError` with descriptive messages

5. **Edge Cases**
   - Booking more seats than available should fail gracefully (return `False`)
   - Booking the exact remaining seats should succeed and mark the event as full
   - Creating an event with duplicate `event_id` should raise `ValueError`
   - Seats requested of 0 or negative should raise `ValueError`

6. **String Representations**
   - `Event.__str__()` returns `f"Event: {title} ({available_seats()}/{capacity} seats available)"`
   - `Booking.__str__()` returns `f"Booking: {booking_id} for {customer_name} - {seats_requested} seats"`

### Deliverable

Provide a complete Python script that implements the above classes and includes a `main()` block that:
1. Creates a booking system
2. Creates 3 events with different capacities
3. Attempts various bookings (some successful, some failing)
4. Lists all events with their seat availability
5. Prints the final state of the system
