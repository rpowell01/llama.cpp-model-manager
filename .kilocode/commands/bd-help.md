Show help for all available bd slash commands.

```bash
bd help
```

**Available bd commands:**
- `/bd-prime` - Load complete workflow context (SSOT)
- `/bd-ready` - Show issues ready to work
- `/bd-list` - List issues with filters
- `/bd-show` - Show issue details
- `/bd-create` - Create new issue
- `/bd-update` - Update issue (claim, status, etc.)
- `/bd-close` - Close/complete issue
- `/bd-dep` - Manage dependencies
- `/bd-dolt-push` - Sync with remote
- `/bd-help` - Show this help
